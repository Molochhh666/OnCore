LOCAL DATA SETTINGS

Connect data

The app runs on your PC. It reads broker candles only; it cannot access credentials or place orders. Your private config.json is excluded from GitHub.

MetaTrader 5 broker feed · default

Open MT5 and sign in before starting TradingGuru. The first start file installs the data connector. The app reads candles and bid/ask prices from the terminal, not your account positions.

{ "market_source": "mt5", "mt5_symbols": { "EUR/USD": "EURUSD" } }
Twelve Data · optional FX reference prices

This needs a provider key entered in your private config file. Plans and quotas change. FX spot quotes may differ from your broker’s CFD price.

Check provider plans ↗{ "market_source": "twelve_data", "twelve_data_api_key": "YOUR_KEY" }
Local AI · Ollama

The first start file installs the free local model. Headlines and chart context are sent to Ollama on this PC; if it is unavailable, the app withholds a signal.

Get Ollama ↗
Headlines · GDELT DOC API

Public news search, no key required. Coverage, relevance, and publication delay vary by publisher. It is not a low-latency newswire.

Broker chart CSV

Import candles with columns: datetime, open, high, low, close. Use UTC timestamps and candles from your broker.
